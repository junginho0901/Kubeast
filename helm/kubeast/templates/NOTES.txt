▸ Open the gateway

{{- if eq .Values.gateway.service.type "NodePort" }}
  NodePort: open port {{ .Values.gateway.service.nodePort }} on a node's IP:
    http://<node-ip>:{{ .Values.gateway.service.nodePort }}
{{- else if eq .Values.gateway.service.type "LoadBalancer" }}
  Once the LoadBalancer has an external IP:
    kubectl -n {{ .Release.Namespace }} get svc gateway
{{- else }}
  Port-forward, then open it in a browser:
    kubectl -n {{ .Release.Namespace }} port-forward svc/gateway 8000:8000
    http://localhost:8000
{{- end }}
  Signing in as admin with no cluster registered opens the /setup page.

▸ First admin account

  ID:       {{ .Values.admin.email }}
  Password: generated by the chart — read it with

    kubectl -n {{ .Release.Namespace }} get secret {{ include "kubeast.secretsName" . }} \
      -o jsonpath='{.data.DEFAULT_ADMIN_PASSWORD}' | base64 -d ; echo

  ⚠ Change the password after you sign in.

{{- if .Values.ai.enabled }}
▸ AI models

  After signing in, register an OpenAI, Anthropic, Gemini … key on
  Admin > AI Models to turn on the chat.
{{- else }}
▸ AI off (ai.enabled: false)

  Installed without ai-service, tool-server and the ModelConfig controller.
  To turn it on, upgrade with --set ai.enabled=true.
{{- end }}

▸ Upgrading

  helm upgrade {{ .Release.Name }} oci://ghcr.io/junginho0901/charts/kubeast --version <version> \
    -n {{ .Release.Namespace }} --reset-then-reuse-values

  --reuse-values keeps this version's defaults and stops on values a later version added.
